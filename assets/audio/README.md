# 🔊 Audio Files - SARH Attendance System

هذا المجلد يحتوي على ملفات الصوت المستخدمة في نظام الحضور.

## الملفات المطلوبة

| الملف | الوصف | المدة المقترحة |
|-------|-------|----------------|
| `radar-beep.mp3` | صوت عند مرور الرادار على موقع المستخدم | 0.1 - 0.3 ثانية |
| `success.mp3` | صوت نجاح تسجيل الحضور/الانصراف | 0.5 - 1 ثانية |
| `error.mp3` | صوت خطأ أو فشل | 0.3 - 0.5 ثانية |

## مصادر مجانية للأصوات

1. **Freesound.org** - https://freesound.org
2. **Mixkit** - https://mixkit.co/free-sound-effects/
3. **Pixabay** - https://pixabay.com/sound-effects/

## ملاحظات تقنية

- **الصيغة**: MP3 (مدعومة في جميع المتصفحات)
- **معدل البت**: 128kbps كافي
- **القنوات**: Mono أو Stereo
- **حجم الملف**: يُفضل أقل من 50KB لكل ملف

## مثال للتحميل

```bash
# باستخدام curl
curl -o radar-beep.mp3 "https://example.com/beep.mp3"
```

**ملاحظة:** الأصوات اختيارية. النظام يعمل بدونها ولكنها تُحسن تجربة المستخدم.
